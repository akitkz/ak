# АвтоКит — демо интернет-магазина (RU / KZ)

Статическая витрина для теста на **GitHub Pages**.  
**Нет** API-ключей, паролей, токенов Kaspi/Halyk/Beksar — только публичные контакты.

## Что есть

- Каталог (демо-товары в `data/products.json`)
- Поиск по артикулу / названию
- Корзина → заявка в **WhatsApp**
- Языки **RU / KZ**
- Черновики **оферты** и **политики конфиденциальности**
- Ссылка на Kaspi-магазин (публичная)

## Чего нет (намеренно)

- Оплата на сайте
- API поставщиков, Beksar, Kaspi Merchant
- База заказов, личный кабинет
- Секреты в коде

Это следующий этап на **отдельном сервере**, не в публичном GitHub.

## Как залить на GitHub

1. Создайте репозиторий, загрузите **все файлы** этой папки в корень.
2. Settings → Pages → branch `main`, folder `/ (root)`.
3. Сайт: `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/`

## Как менять товары

Редактируйте `data/products.json` (артикул, цена, категория, stock: `in` | `order`).

## Импорт прайса Excel (Алтын Авто)

Формат колонок:
`Код | Номенклатура | Производитель | Марка автомобиля | Артикул | Оригинальный номер | Остаток | Цена`

### Наценка

Цена на сайте = **закупочная × (1 + наценка%)**.  
По умолчанию **15%**. Меняется параметром `--markup`.

### Команды (на компьютере)

```bash
pip install pandas openpyxl
python scripts/import_altyn.py price-list.xlsx --markup 15 --limit 500
python scripts/import_altyn.py price-list.xlsx --markup 20 --limit 0 --full
```

- `--limit 500` — для GitHub (лёгкий файл)
- `--limit 0 --full` — весь прайс (~70 тыс. позиций, тяжёлый JSON)

После импорта залейте обновлённый `data/products.json` на GitHub.

### Interkom (opt.interkom.kz)

Прайс с сайта Interkom обычно доступен **после входа** в кабинет.  
Когда будет файл Excel/CSV или API — подключим тем же скриптом (адаптируем колонки).  
Логины и пароли в GitHub **не кладём**.
